Що таке Bootstrap?

Bootstrap — інструментарій відкритого коду для розробки на HTML, CSS і JavaScript. Використовується для створення адаптивних і мобільно-оптимізованих сайтів: дає готові стилі та компоненти (сітку, кнопки, картки, модальні вікна, JS-плагіни), тож інтерфейс не доводиться будувати з нуля.

Framework vs Library

Бібліотека (library)
Набір готового коду (функцій, класів), який ми самі викликаємо, коли він потрібен. Ми керуємо потоком виконання програми.
Фреймворк (framework)
Готова структура проєкту, яка сама "викликає" наш код у потрібний момент. Ми пишемо код за правилами фреймворку, а не навпаки.
Головна відмінність
"Хто керує потоком": з бібліотекою керуємо ми, з фреймворком — він керує нами (Inversion of Control).

Перевизначення кольорів через CSS-змінні (--bs-*)

Bootstrap 5.3 генерує CSS custom properties, і їх можна перевизначити прямо у своєму CSS — без будь-якої збірки, навіть якщо Bootstrap підключений через CDN, як тут.

/* sass/pages/_intro-cdn.sass */
.theme-custom
  .btn-primary
    --bs-btn-bg: #ff6600
    --bs-btn-border-color: #ff6600
    --bs-btn-hover-bg: #cc5200
    --bs-btn-hover-border-color: #bf4d00
    --bs-btn-active-bg: #bf4d00
    --bs-btn-active-border-color: #b34700

  .alert-primary
    --bs-alert-color: #7a3300
    --bs-alert-bg: #ffe0cc
    --bs-alert-border-color: #ffc299

Зверніть увагу: перевизначення лише --bs-primary у :root тут не спрацює для кнопок. Bootstrap рахує кольори кнопок ще на етапі Sass-компіляції і записує їх у .btn-primary як окремі готові змінні (--bs-btn-bg, --bs-btn-hover-bg тощо), а не бере --bs-primary напряму. Тому доводиться перевизначати змінні кожного компонента окремо — точкове правило на готовому Bootstrap із CDN. Повністю перерахувати всю палітру одразу (кнопки, бейджі, форми, тіні тощо) можна лише перевизначивши Sass-змінні до компіляції — див. 02. Bootstrap через pnpm.
