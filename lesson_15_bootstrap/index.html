Заняття 15: Bootstrap

Framework vs Library · CDN vs pnpm · Layout & Grid · Content · Forms · Components · Helpers & Utilities · Icons · Конкуренти Bootstrap

  1. 01. Що таке Bootstrap. Підключення через CDN — визначення framework/library, перший запуск через <link> і <script> з CDN.
  2. 02. Підключення Bootstrap через pnpm — та сама кнопка, але Bootstrap встановлений як залежність проєкту (pnpm add bootstrap).
  3. 03. Перевизначення кольорів — зміна основної палітри через CSS-змінні та через Sass-змінні до компіляції.
  4. 04. Layout та Grid — container, row, col, breakpoints, gutters.
  5. 05. Content — Reboot, Typography, Images, Tables, Figures.
  6. 06. Forms — стилізація полів вводу, чекбоксів, кнопок відправки.
  7. 07. Components — accordion, alert, badge, card, modal, navbar, carousel, tabs, tooltip та інші готові UI-компоненти.
  8. 08. Helpers & Utilities — допоміжні класи для швидкої стилізації без написання CSS.
  9. 09. Bootstrap Icons — підключення іконок через CDN і через pnpm.
  10. 10. Конкуренти Bootstrap — Tailwind CSS, Foundation, Bulma, Materialize, Semantic UI.
