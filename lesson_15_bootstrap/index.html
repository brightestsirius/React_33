Заняття 15: Bootstrap

Framework vs Library · CDN vs pnpm · Layout & Grid · Content · Forms · Components · Helpers & Utilities · Icons · Конкуренти Bootstrap

  1. 01. Bootstrap через CDN + перевизначення кольорів — визначення framework/library, перший запуск через <link> і <script> з CDN, а також точкове перевизначення палітри через CSS-змінні (--bs-*).
  2. 02. Bootstrap через pnpm + Sass-змінні — Bootstrap встановлений як залежність проєкту (pnpm add bootstrap) і компілюється власним gulp + Sass із перевизначеними $primary/$danger ще до компіляції.
  3. 03. Layout та Grid — container, row, col, breakpoints, gutters.
  4. 04. Content — Reboot, Typography, Images, Tables, Figures.
  5. 05. Forms — стилізація полів вводу, чекбоксів, кнопок відправки.
  6. 06. Components — accordion, alert, badge, card, modal, navbar, carousel, tabs, tooltip та інші готові UI-компоненти.
  7. 07. Helpers & Utilities — допоміжні класи для швидкої стилізації без написання CSS.
  8. 08. Bootstrap Icons — підключення іконок через CDN і через pnpm.
  9. 09. Конкуренти Bootstrap — Tailwind CSS, Foundation, Bulma, Materialize, Semantic UI.
  10. 10. Приклад виконання ДЗ (HW 15.1) — адаптивна сітка HEADER/LEFT/MAIN/RIGHT/FOOTER, що згортається з 3 до 2 і до 1 колонки, дворівневе меню, слайдер зображень, акордеон і форма.
