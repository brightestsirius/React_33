# ДЗ 12. TypeScript: замовлення в кав'ярні

Потрібно описати типи і написати функції, які рахують вартість замовлення в кав'ярні.
Теми: типізація змінних і функцій, `enum`, `interface`, `as const`, необов'язкові параметри.

Без форм і введення від користувача: замовлення задається об'єктом прямо в коді, результати виводяться в консоль.

- **Напій** (`Drink`) — одна чашка: яка кава, розмір, чи з молоком, чи з сиропом.
- **Замовлення** (`Order`) — те, що замовив один клієнт: один або кілька напоїв.

## Підготовка

```bash
npm i
npx tsc --watch
```

Код писати в `scripts/script.ts`. `index.html` уже підключає скомпільований `scripts/script.js` — відкрити сторінку через Live Server, результат виводиться в консоль.

## Завдання

### 1. Enum

| Enum          | Значення                                                   |
| ------------- | ---------------------------------------------------------- |
| `DrinkSize`   | `Small = "S"`, `Medium = "M"`, `Large = "L"`               |
| `OrderStatus` | `New = "Нове"`, `Paid = "Оплачене"`, `Ready = "Готове"`    |

### 2. Константи

Об'єкт `PRICES` з `as const`:

| Ключ           | Значення | Опис                         |
| -------------- | -------- | ---------------------------- |
| `MILK`         | 15       | додавання молока, грн        |
| `SYRUP`        | 10       | сироп, грн                   |
| `MEDIUM_EXTRA` | 10       | доплата за розмір `Medium`   |
| `LARGE_EXTRA`  | 20       | доплата за розмір `Large`    |

### 3. Інтерфейси

**`Drink`**

| Поле        | Тип         | Примітка          |
| ----------- | ----------- | ----------------- |
| `name`      | `string`    |                   |
| `basePrice` | `number`    |                   |
| `size`      | `DrinkSize` |                   |
| `withMilk`  | `boolean`   |                   |
| `syrup`     | `string`    | необов'язкове     |

**`Order`**

| Поле       | Тип           | Примітка          |
| ---------- | ------------- | ----------------- |
| `id`       | `number`      | тільки для читання |
| `customer` | `string`      |                   |
| `drinks`   | `Drink[]`     |                   |
| `status`   | `OrderStatus` |                   |

### 4. Функції

Параметри і значення, що повертається, мають бути явно типізовані.

| Функція                                 | Приймає                        | Повертає                                  |
| --------------------------------------- | ------------------------------ | ----------------------------------------- |
| `getDrinkPrice(drink)`                  | один напій (`Drink`)           | ціну цього напою, `number`                |
| `getOrderTotal(order, discountPercent?)` | замовлення (`Order`) і знижку  | загальну суму за всі напої, `number`      |

**`getDrinkPrice`** — рахує ціну однієї чашки: `basePrice` + доплата за розмір + молоко (якщо `withMilk`) + сироп (якщо вказано `syrup`).

**`getOrderTotal`** — проходить по всіх напоях замовлення, для кожного викликає `getDrinkPrice` і складає результати. `discountPercent` — необов'язковий, за замовчуванням 0. Результат округлити до цілого.

### 5. Перевірка

Створити в коді замовлення і вивести в консоль ціну одного напою, суму замовлення і суму зі знижкою:

```ts
const order: Order = {
    id: 1,
    customer: "Олена",
    status: OrderStatus.New,
    drinks: [
        { name: "Лате", basePrice: 60, size: DrinkSize.Large, withMilk: true, syrup: "ваніль" },
        { name: "Еспресо", basePrice: 45, size: DrinkSize.Small, withMilk: false },
    ],
};

console.log(getDrinkPrice(order.drinks[0])); // 105 = 60 + 20 (Large) + 15 (молоко) + 10 (сироп)
console.log(getOrderTotal(order));           // 150 = 105 + 45
console.log(getOrderTotal(order, 10));       // 135 = 150 - 10%
```
