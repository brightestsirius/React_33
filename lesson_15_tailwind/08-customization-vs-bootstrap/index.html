Кастомізація Tailwind CSS

tailwind.config: theme, colors, spacing

У продакшн-проєкті налаштування живе у файлі tailwind.config.js. Ключові розділи:

  • content — де шукати класи (файли HTML/JS), щоб знати, які утиліти лишити у збірці.
  • theme — базові значення (кольори, шрифти, розміри); theme.extend — додає, не замінюючи стандартні.
  • screens — власні брейкпоінти для responsive-префіксів.
  • colors / spacing — брендові кольори та власна шкала відступів.
  • plugins — розширення новими утилітами (наприклад, @tailwindcss/forms, @tailwindcss/typography).
  • presets — готова базова конфігурація, яку можна перевикористовувати між проєктами.

На цій сторінці вище підключений такий конфіг — і клас bg-brand та p-18 вже працюють, хоча їх немає у стандартній палітрі Tailwind:

p-18 (4.5rem)
// tailwind.config.js
module.exports = {
  content: ["./**/*.html"],
  theme: {
    extend: {
      colors: {
        brand: { DEFAULT: "#cc3333", light: "#e88", dark: "#911" },
      },
      spacing: { 18: "4.5rem" },
    },
  },
  plugins: [],
};

Власні стилі поверх утиліт

У реальній збірці (з PostCSS) для повторюваних комбінацій утиліт використовують @layer components і @apply у CSS-файлі: 

/* styles.css */
@layer components {
  .btn-brand {
    @apply bg-brand hover:bg-brand-dark text-white font-bold py-2 px-4 rounded;
  }
}

<button class="btn-brand">Кнопка</button>

Без збірки (Play CDN, як тут) @apply недоступний — повторне використання досягається копіюванням набору класів або компонентами фреймворку (React/Vue/Angular).

Tailwind CSS vs Bootstrap: принципова відмінність

Обидва — популярні CSS-фреймворки, але з різною філософією іменування класів.

Bootstrap Tailwind CSS
Component-based: готові компоненти зі своїм CSS Utility-first: маленькі класи по одній властивості
btn btn-primary bg-blue-500 text-white font-bold py-2 px-4 rounded
Швидкий старт: готовий вигляд "з коробки" Швидкий у кастомізації: унікальний дизайн без перезапису чужого CSS
Кастомізація через Sass-змінні / CSS custom properties Кастомізація через tailwind.config (theme/extend)

Одна й та сама кнопка двома способами:

Bootstrap

<button class="btn btn-primary">
  Кнопка
</button>

Tailwind

<button class="bg-blue-500 text-white
  font-bold py-2 px-4 rounded">
  Кнопка
</button>

Обидва підходи дозволяють кастомізацію під власні потреби — різниця у тому, звідки ми стартуємо: від готового компонента (Bootstrap) чи від набору "цеглинок" (Tailwind).
