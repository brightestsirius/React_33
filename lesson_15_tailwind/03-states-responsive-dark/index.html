States, Responsive Design, Dark Mode

У Tailwind стани, брейкпоінти й тема — це просто префікси перед звичайним утилітарним класом: hover:, md:, dark:.

Hover, Focus та інші стани

Наведіть курсор на кнопку або клікніть у поле вводу.

Посилання з hover:underline 
<button class="bg-blue-500 hover:bg-blue-700 active:bg-blue-800 ...">
<input class="... focus:outline-none focus:ring-2 focus:ring-blue-500 ...">
<a class="text-blue-600 hover:underline">

Responsive Design

Брейкпоінти за замовчуванням: sm 640px, md 768px, lg 1024px, xl 1280px. Підхід — mobile-first: базовий клас діє завжди, префіксований — від вказаної ширини і ширше. Змініть ширину вікна браузера, щоб побачити зміну кількості колонок.

Dark Mode

Клас dark: застосовує стилі, коли на <html> присутній клас dark (стратегія darkMode: "selector" в конфігурації). Натисніть кнопку — перемкнеться весь документ.

Картка, що реагує на тему

bg-white → dark:bg-slate-800, text-slate-900 → dark:text-white 

tailwind.config = { darkMode: "selector" };

<button onclick="document.documentElement.classList.toggle('dark')">

<div class="bg-white dark:bg-slate-800 text-slate-900 dark:text-white">
