Що таке Tailwind CSS?

Tailwind CSS — це утилітарний (utility-first) фреймворк для CSS. Замість написання власних CSS-класів (.card, .btn-primary тощо) ми стилізуємо елементи прямо в розмітці, комбінуючи готові утилітарні класи — кожен з яких відповідає за одну властивість CSS.

Підключення через CDN (для навчання)

Для продакшн-проєктів Tailwind зазвичай встановлюють як залежність (pnpm/npm) і компілюють збіркою (Vite, PostCSS). Але для швидкого старту й навчання є Play CDN — один <script>, і всі утиліти вже працюють без жодної збірки. Саме так підключені всі приклади цього заняття. 

<script src="https://cdn.tailwindcss.com"></script>

Traditional CSS vs Utility-first

Той самий результат — однакова кнопка, два підходи.

Звичайний CSS

<button class="btn">Кнопка</button>

.btn {
  background-color: #3b82f6;
  color: white;
  font-weight: bold;
  padding: 0.5rem 1rem;
  border-radius: 0.25rem;
}

Tailwind (utility-first)

<button class="bg-blue-500 text-white
  font-bold py-2 px-4 rounded">
  Кнопка
</button>

Жодного окремого CSS-файлу для кнопки не знадобилось — весь вигляд описаний класами прямо в HTML. Змінити стиль так само просто, як змінити/додати клас.

Переваги Tailwind CSS

  • Швидкість розробки

    Стилізація без перемикання між HTML і CSS-файлом.

  • Дизайн-система з коробки

    Обмежена палітра кольорів/відступів → консистентний UI.

  • Гнучкість

    Повний контроль над кожним елементом без "боротьби" з чужими стилями.

  • Мінімум зайвого CSS

    При збірці невикористані класи видаляються (тут показано без збірки).

  • Легкий вхід

    Назви класів здебільшого інтуїтивно зрозумілі.

  • Спільнота

    Плагіни, готові компоненти, UI-кіти (Tailwind UI, DaisyUI тощо).

Utility-First Fundamentals: комбінування класів

Складний вигляд картки будується простим складанням маленьких утиліт: фон, рамка, закруглення, тінь, внутрішній відступ, flex-розкладка.
