Layout, Flexbox & Grid

Утиліти розкладки визначають, як елемент відображається і як розташовується відносно інших.

Layout: container, display, position, overflow, z-index

display: block / inline-block / flex / grid / hidden

block inline-block hidden на <640px

position: relative / absolute + top/right/bottom/left

top-2 left-2
bottom-2 right-2

overflow-hidden / overflow-auto

Дуже довгий текст, що не поміщається в один рядок і не поміщається у видиму висоту блока, тому з'являється прокрутка завдяки класу overflow-auto. Спробуйте прокрутити цей блок вниз і вправо.

z-index: порядок накладання

z-10
z-20
<span class="block"> / <span class="inline-block"> / <span class="hidden sm:inline-block">
<div class="relative"><div class="absolute top-2 left-2"></div></div>
<div class="overflow-auto">
<div class="z-10"> / <div class="z-20">

Flexbox

flex-direction, justify-content, align-items, flex-wrap, gap.

justify-between розводить елементи по краях, align-items: center вирівнює по вертикалі попри різну висоту.

order: змінюємо візуальний порядок без зміни HTML

1-й у HTML
2-й у HTML
3-й у HTML
<div class="flex justify-between items-center gap-2">
  <div class="h-10 w-10"></div>
  <div class="h-14 w-10"></div>
</div>

<div class="order-3">1-й у HTML</div>
<div class="order-1">2-й у HTML</div>

Grid

grid-template-columns через grid-cols-*, а елемент може займати кілька колонок через col-span-*.

col-span-4 (шапка)
1
col-span-2
1
<div class="grid grid-cols-4 gap-2">
  <div class="col-span-4">шапка</div>
  <div class="col-span-1">1</div>
  <div class="col-span-2">2 колонки</div>
  <div class="col-span-1">1</div>
</div>
