Медіа-запити

Змінюй ширину вікна браузера, щоб побачити, як спрацьовують умови.

1. min-width / max-width

Один і той самий блок показує різний напис залежно від ширини вікна.

📱 Мобільний: ширина < 600px 💻 Планшет: 600px–899px 🖥️ Десктоп: ≥ 900px

2. Mobile-first проти Desktop-first

Два способи писати медіа-запити — відрізняються напрямком умов.

Mobile-first

Базові стилі — для мобільних, розширюємо через min-width.

.el { font-size: 14px; }

@media (min-width: 768px) {
  .el { font-size: 16px; }
}

Desktop-first

Базові стилі — для десктопа, звужуємо через max-width.

.el { font-size: 16px; }

@media (max-width: 767px) {
  .el { font-size: 14px; }
}

3. orientation

Розтягни вікно вужче за висоту або ширше — напис зміниться.

⬆️ portrait ➡️ landscape

4. prefers-color-scheme

Стиль залежить від теми операційної системи/браузера, а не від ширини екрана.

Ця картка сама підлаштовується під світлу чи темну тему системи

5. prefers-reduced-motion

Якщо в системі ввімкнено "зменшення руху", анімація вимикається автоматично.

6. Комбінування умов: and, кома (або), not

screen and (min-width: 700px)
and
(max-width: 500px), (min-width: 1100px)
кома = «або»
not all and (min-width: 700px)
not

7. Діапазон ширини (range)

Стиль застосовується лише в межах 600px–1000px.

@media (min-width: 600px) and (max-width: 1000px) { ... }

Активно тільки в діапазоні 600–1000px
