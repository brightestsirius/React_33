Layout у Bootstrap

Layout — це система розміщення й структурування елементів на сторінці. У Bootstrap вона будується на кількох поняттях:

  • Breakpoints — точки перелому екрану (sm, md, lg, xl, xxl), на яких змінюється вигляд сітки.
  • Containers — обгортка контенту, задає максимальну ширину та центрування.
  • Grid — система рядів і колонок для побудови макетів.
  • Columns — колонки всередині сітки, автоматично діляться на рівні частини.
  • Gutters — проміжки між колонками/рядами.
  • Utilities — допоміжні класи для відступів, вирівнювання тощо.
  • Z-index — керування порядком накладання елементів.
