Перевизначення основних кольорів Bootstrap

Bootstrap дозволяє змінити свою колірну палітру (primary, danger тощо) двома способами: через CSS-змінні у браузері (швидко, але частково) або через Sass-змінні до компіляції (повністю, але потребує збірки).

Спосіб 1. CSS-змінні (--bs-*)

Bootstrap 5.3 генерує CSS custom properties, і їх можна перевизначити прямо у своєму CSS — без будь-якої збірки, навіть якщо Bootstrap підключений через CDN, як тут.

/* sass/pages/_custom-colors.sass */
.theme-custom
  .btn-primary
    --bs-btn-bg: #ff6600
    --bs-btn-border-color: #ff6600
    --bs-btn-hover-bg: #cc5200
    --bs-btn-hover-border-color: #bf4d00
    --bs-btn-active-bg: #bf4d00
    --bs-btn-active-border-color: #b34700

  .alert-primary
    --bs-alert-color: #7a3300
    --bs-alert-bg: #ffe0cc
    --bs-alert-border-color: #ffc299

Зверніть увагу: перевизначення лише --bs-primary у :root тут не спрацює для кнопок. Bootstrap рахує кольори кнопок ще на етапі Sass-компіляції і записує їх у .btn-primary як окремі готові змінні (--bs-btn-bg, --bs-btn-hover-bg тощо), а не бере --bs-primary напряму. Тому доводиться перевизначати змінні кожного компонента окремо.

Спосіб 2. Sass-змінні (до компіляції)

Якщо Bootstrap підключений як залежність (pnpm add bootstrap) і компілюється разом із власним Sass — можна перевизначити його змінні ще до того, як вони перетворяться на CSS. Усі кольори в Bootstrap задані через !default, тож власне значення, вказане раніше, "перекриває" дефолтне: 

// sass/main.sass

// 1. спочатку свої значення
$primary: #ff6600
$danger: #e63946

// 2. потім сам Bootstrap — він побачить вже змінені змінні
@import "bootstrap/scss/bootstrap"

Цей спосіб перераховує все одразу: кнопки, бейджі, алерти, форми, тіні, hover/active стани — і саме згенеровані CSS-змінні (--bs-btn-bg і подібні) вже міститимуть ваш колір. Компілюється тим самим gulpfile.js, що вже є в цьому проєкті (gulp dev / gulp build).

Коли який спосіб

  • Точкове правило на готовому Bootstrap із CDN — CSS-змінні (спосіб 1).
  • Своя тема з нуля через збірку (gulp + Sass) — Sass-змінні (спосіб 2), це "правильний" спосіб кастомізації Bootstrap.
