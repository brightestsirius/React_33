Властивість position

Static, relative, absolute, fixed, sticky та z-index.

static relative absolute fixed

1. position: static

Це стандартне значення. top, right, bottom і left не працюють.

static

2. position: relative

Елемент зміщується від свого початкового місця, але місце в потоці зберігається.

1

3. position: absolute

Елемент позиціонується відносно найближчого предка з position не static.

4. z-index

z-index визначає, який позиціонований елемент буде вище.

5. position: fixed і sticky

Кнопка внизу праворуч має position: fixed. Навігація зверху має position: sticky. Прокрутіть сторінку, щоб побачити різницю.
